# Assets

Place your image files here. All are optional — the video stage
uses placeholder graphics if any are missing.

## speaker_a.png
Left speaker illustration (your female host character).
PNG with transparency recommended. Roughly portrait aspect (e.g. 340×420px
or similar tall crop). The video stage will resize/crop to fit.

## speaker_b.png
Right speaker illustration (your male co-host character).
Same format as speaker_a.png.

## logo.png
Your channel logo, top-right corner.
PNG with transparency. Resized to ~140×60px in the video.
E.g. your "English LEAP Podcast" logo from the reference image.

## Tips
- PNG with transparent background works best — the dark background
  shows through rather than getting a white box around the image.
- Higher resolution is fine — the stage downscales cleanly with LANCZOS.
- The reference image style uses illustrated/vector art style characters,
  but any image works (photo, illustration, etc).
